# Slides

PDF exports of the training decks.

The decks themselves are built from Python and live outside this repository; only the
exported PDFs belong here, added by hand.

| Pattern | File |
|---|---|
| Decorator | `Decorator.pdf` |
| Bridge | `Bridge.pdf` |
| Composite | `Composite.pdf` |

> This folder is deliberately **not checked out** on the maintainer's machine. It is
> excluded by `git sparse-checkout`, so the files live on GitHub and are added through the
> web interface. Running `git sparse-checkout disable` would bring them down locally.
